================================================================================
HOW IT WORKS
================================================================================

1. SAMPLE IDs ARE TRACKED
   - Each sample in the dataset has a unique 'name' field containing its ID
   - Example IDs: 258985354, 260947588, 255767243, 261893617, etc.
   - These IDs are now saved in the CSV exports

2. CSV FILES WITH SAMPLE IDS
   Location: /home3/mercury/1_HE_SAC/2_train/1_DFT_only/prediction_results/
   
   Files:
   - BE_deltaO_predictions_20260127_164237.csv (270 samples)
   - BE_deltaOH_predictions_20260127_164237.csv (258 samples)
   
   Each CSV contains:
   ├─ sample_name: SAMPLE ID (the key for identification!)
   ├─ dataset_from: Which dataset it came from (e.g., "sac_2_components")
   ├─ sample_idx: Index in the combined dataset
   ├─ target: DFT-calculated binding energy (ground truth)
   ├─ prediction: ML model prediction (ensemble average of 10 models)
   ├─ error: Prediction error (pred - target)
   └─ abs_error: Absolute prediction error

3. LOOKUP UTILITY SCRIPT
   Script: lookup_sample.py
   
   Usage Examples:
   
   # Lookup all predictions for sample ID 258985354
   $ python lookup_sample.py --id 258985354
   
   # Lookup only deltaO predictions for a sample
   $ python lookup_sample.py --id 260947588 --property deltaO
   
   Output shows:
   - Dataset source
   - DFT target value
   - ML prediction value
   - Prediction error and quality rating

================================================================================
PRACTICAL EXAMPLE: IDENTIFYING A POINT
================================================================================

Say you see an interesting point in the deltaO parity plot with:
- Target ≈ 2.3 eV
- Prediction ≈ 2.7 eV

Steps to identify it:
1. Find the CSV: BE_deltaO_predictions_20260127_164237.csv
2. Look for row with target ≈ 2.3
3. Read the sample_name column: 260947588
4. Run: python lookup_sample.py --id 260947588

Output tells you:
- Dataset: sac_2_components
- Sample index: 22
- Both O and OH binding energies for this structure
- Prediction quality assessment
